# Open the assembly of a file

1. Open a source file, such as a C++ or Rust file.
2. Run **Open Artifact** from the editor context menu, or press `Ctrl+Alt+A` (`Cmd+Alt+A` on macOS).
3. Select **Assembly**.

The assembly opens beside the source. Select a source line to highlight its instructions. Select an instruction to highlight its source line.

When you save the source, the assembly compiles again. The status bar shows the state of the compile. Click it for the artifact actions.

Other artifacts include LLVM IR, binary disassembly, optimization remarks, and the control-flow graph.
