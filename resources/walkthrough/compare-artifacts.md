# Compare two builds

**Compare Artifacts** opens the output of two builds in a diff editor.

1. Open a source file.
2. Run **Compare Artifacts**, or press `Ctrl+Alt+C` (`Cmd+Alt+C` on macOS).
3. Select the left build and the right build. A build is a compilation variant or a preset.
4. Select the artifact kind, such as **Assembly**.

For example, compare a preset with `-O0` and a preset with `-O2` to see what the optimizer changes.
